# Agent-OS Development Rules

**These rules are mandatory for all development in agent-os.**

---

## 1. No Hardcoded Secrets or URLs

**NEVER** put these directly in code:
- Database URLs (`postgres://...`)
- API keys
- Tokens
- Passwords
- Connection strings

**ALWAYS** use:
- `.env` or `.env.local` files
- Environment variables via `process.env`

```typescript
// ❌ WRONG
const pool = new Pool({ connectionString: 'postgres://user:pass@localhost/db' });

// ✅ CORRECT
import 'dotenv/config';
const pool = new Pool({ connectionString: process.env.DATABASE_URL });
```

---

## 2. DRY Configuration

Reuse configs across scripts. Create shared modules for:
- Database/pool connections
- SDK client initialization
- Environment loading

```typescript
// packages/scripts/src/config.ts
import 'dotenv/config';

export const config = {
  apiEndpoint: process.env.API_ENDPOINT || 'http://api.localhost:3000/graphql',
  authEndpoint: process.env.AUTH_ENDPOINT || 'http://auth.localhost:3000/graphql',
};

export function getAuthHeaders(token?: string) {
  return token ? { Authorization: `Bearer ${token}` } : {};
}
```

---

## 3. NO Raw SQL or Raw GraphQL Strings

**NEVER** write raw SQL or raw GraphQL query strings in this workspace when a generated SDK exists.

If you absolutely must write SQL (emergency hack), put it in `sql-hacks/` folder with clear documentation of why.

**ALWAYS** use:
1. `@constructive-io/node` SDK for platform operations
2. Generated SDK (from codegen) for database CRUD
3. GraphQL queries/mutations ONLY if the SDK is missing a feature (and fix the SDK first)

```typescript
// ❌ WRONG (Raw SQL)
await pool.query('INSERT INTO contacts (first_name) VALUES ($1)', ['Dan']);

// ❌ WRONG (Raw GraphQL String)
await client.execute(`mutation { createContact(input: { contact: { firstName: "Dan" } }) { contact { id } } }`);

// ✅ CORRECT (Typed SDK)
await client.contact.create({
  data: { firstName: 'Dan', entityId: orgId },
  select: { id: true },
}).unwrap();
```

---

## 4. Use the Right SDK

| Context | SDK |
|---------|-----|
| **Node.js** (scripts, CLI, server) | `@constructive-io/node` |
| **Browser** (React, Next.js client) | `@constructive-io/sdk` |
| **Per-Database Operations** | Generated SDK from `@constructive-io/graphql-codegen` |

```typescript
// Platform operations (provision, auth)
import { createClient } from '@constructive-io/node';

// Per-database CRUD (after codegen)
import { createClient } from '@agentic-sdk/sdk';
```

---

## 5. Codegen with Skills

When running codegen, **always** enable skills generation:

```typescript
import { generate } from '@constructive-io/graphql-codegen';

await generate({
  endpoint: `http://app-public-${dbName}.localhost:3000/graphql`,
  output: './generated/agent-os-sdk',
  orm: true,
  nodeHttpAdapter: true,
  docs: {
    readme: true,
    agents: true,
    skills: true,  // ← ALWAYS ENABLE
  },
});
```

---

## 6. GraphQL & TypeScript Only

**Prefer:**
- GraphQL mutations/queries
- TypeScript for all code
- Generated types from codegen

**Avoid:**
- Raw SQL
- JavaScript (use TypeScript)
- Untyped operations

---

## 7. Workspace Package References

**NEVER** use relative path imports across packages:

```typescript
// ❌ WRONG
import { something } from '../../other-package/src/thing';

// ✅ CORRECT
import { something } from '@agent-os/other-package';
```

In `package.json`:
```json
{
  "dependencies": {
    "@agent-os/other-package": "workspace:*"
  }
}
```

---

## 8. Use Makage for Builds

Every package must use `makage` for builds with `dist/` folder publishing:

```json
{
  "name": "@agent-os/my-package",
  "main": "index.js",
  "module": "esm/index.js",
  "types": "index.d.ts",
  "publishConfig": {
    "access": "public",
    "directory": "dist"
  },
  "scripts": {
    "clean": "makage clean",
    "build": "makage build",
    "prepublishOnly": "npm run build"
  },
  "devDependencies": {
    "makage": "0.1.10"
  }
}
```

**NEVER:**
- Use manual rimraf/copyfiles scripts
- Use `exports` map pattern
- Skip the `dist/` folder pattern

---

## 9. Package Structure

Every package in `packages/` should follow:

```
packages/my-package/
├── package.json
├── tsconfig.json
├── src/
│   └── index.ts
├── dist/           # Generated by makage build
└── __tests__/      # Optional
```

---

## 10. Environment Files

```
.env              # Default env (gitignored)
.env.local        # Local overrides (gitignored)
.env.example      # Example for developers (committed)
```

---

## Summary Checklist

Before committing, verify:
- [ ] No hardcoded URLs, keys, or secrets
- [ ] Using `.env` for configuration
- [ ] Using SDK (not raw SQL)
- [ ] Using `workspace:*` for internal deps
- [ ] Using `makage` for builds
- [ ] Codegen has `docs.skills: true`
- [ ] All code is TypeScript
